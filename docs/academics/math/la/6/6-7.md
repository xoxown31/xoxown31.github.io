# 📘 Chapter 6-7 – Inner Product Spaces

## 🎯 목표
이 단원에서는 벡터 공간에서 "길이", "거리", "직교성"과 같은 기하학적 개념을 일반화하는 **내적 공간(Inner Product Space)**의 개념을 배우게 됩니다. $R^n$에서 익숙했던 내적의 성질들을 확장하여, 다항식 공간이나 연속 함수 공간과 같은 다양한 벡터 공간에서도 이러한 개념들을 어떻게 정의하고 활용하는지 탐구할 것입니다.

---

## 🟦 Step 1: 내적 공간의 정의

$R^n$에서 두 벡터 $\vec{u}$와 $\vec{v}$의 표준 내적 $\vec{u} \cdot \vec{v}$은 길이, 거리, 각도를 계산하는 데 사용되었습니다. 이제 이 아이디어를 더욱 일반적인 벡터 공간으로 확장해봅시다. 이를 위해 내적의 핵심적인 성질들을 **공리(axiom)**로 삼아 새로운 정의를 만듭니다.

### 📙 [정의] 내적 (Inner Product)
벡터 공간 $V$ 위의 **내적(Inner Product)**은 $V$의 두 벡터 $\vec{u}$와 $\vec{v}$에 대해 실수 $h\vec{u}, \vec{v}i$를 대응시키는 함수이며, 다음 공리들을 만족합니다. (모든 $\vec{u}, \vec{v}, \vec{w}$는 $V$의 벡터이고, $c$는 스칼라입니다.)

1.  **대칭성 (Symmetry Axiom):**
    $$h\vec{u}, \vec{v}i = h\vec{v}, \vec{u}i$$
    *두 벡터의 순서를 바꿔도 내적 값은 같습니다.*

2.  **선형성 (Additivity Axiom):**
    $$h\vec{u} + \vec{v}, \vec{w}i = h\vec{u}, \vec{w}i + h\vec{v}, \vec{w}i$$
    *첫 번째 인수에 대한 덧셈은 분배됩니다.*

3.  **동차성 (Homogeneity Axiom):**
    $$hc\vec{u}, \vec{v}i = ch\vec{u}, \vec{v}i$$
    *첫 번째 인수의 스칼라배는 내적 밖으로 나갈 수 있습니다.* (공리 1에 의해 `$$h\vec{u}, c\vec{v}i = ch\vec{u}, \vec{v}i$$`도 성립합니다!)

4.  **양의 정부호성 (Positive-Definiteness Axiom):**
    $$h\vec{u}, \vec{u}i \ge 0$$
    *그리고*
    $$h\vec{u}, \vec{u}i = 0 \quad \text{if and only if} \quad \vec{u} = \vec{0}$$
    *자기 자신과의 내적은 항상 0보다 크거나 같고, 0이 되는 경우는 오직 영벡터일 때뿐입니다.*

내적이 정의된 벡터 공간 $V$를 **내적 공간(Inner Product Space)**이라고 부릅니다.

---

### 🧠 [예제] $R^2$에서의 내적 확인
임의의 양수 4와 5를 고정하고, $R^2$의 두 벡터 $\vec{u} = (u_1, u_2)$와 $\vec{v} = (v_1, v_2)$에 대해 다음과 같이 내적을 정의해봅시다.
$$h\vec{u}, \vec{v}i = 4u_1v_1 + 5u_2v_2 \quad (1)$$
이것이 내적을 정의하는지 확인하세요.

**예제 해설:**
각 공리를 하나씩 확인합니다.
1.  **대칭성:**
    $$h\vec{u}, \vec{v}i = 4u_1v_1 + 5u_2v_2 = 4v_1u_1 + 5v_2u_2 = h\vec{v}, \vec{u}i$$
    성립합니다.

2.  **선형성:**
    $\vec{w} = (w_1, w_2)$라고 하면,
    $$h\vec{u} + \vec{v}, \vec{w}i = h(u_1+v_1, u_2+v_2), (w_1, w_2)i$$
    $$= 4(u_1+v_1)w_1 + 5(u_2+v_2)w_2$$
    $$= (4u_1w_1 + 5u_2w_2) + (4v_1w_1 + 5v_2w_2)$$
    $$= h\vec{u}, \vec{w}i + h\vec{v}, \vec{w}i$$
    성립합니다.

3.  **동차성:**
    $$hc\vec{u}, \vec{v}i = h(cu_1, cu_2), (v_1, v_2)i = 4(cu_1)v_1 + 5(cu_2)v_2$$
    $$= c(4u_1v_1 + 5u_2v_2) = ch\vec{u}, \vec{v}i$$
    성립합니다.

4.  **양의 정부호성:**
    $$h\vec{u}, \vec{u}i = 4u_1u_1 + 5u_2u_2 = 4u_1^2 + 5u_2^2$$
    $4u_1^2 + 5u_2^2$은 제곱의 합이므로 항상 `$$\ge 0$$` 입니다.
    또한, `$$4u_1^2 + 5u_2^2 = 0$$`이 되려면 $u_1 = 0$이고 $u_2 = 0$이어야만 합니다. 즉, $\vec{u} = \vec{0}$일 때만 0이 됩니다. (영벡터 $h\vec{0}, \vec{0}i = 0$ 또한 성립합니다.)
    성립합니다.

모든 공리가 만족되므로, 식 (1)은 $R^2$ 위에 내적을 정의합니다. 이러한 내적은 각 성분에 "가중치(weight)"를 부여하는 개념으로, 통계학의 가중 최소 제곱법과 같은 곳에서 활용됩니다.

---

### 🧠 [예제] 다항식 공간 $P_n$에서의 내적 확인
$n$차 이하의 모든 다항식으로 이루어진 공간 $P_n$을 생각해봅시다. $t_0, t_1, \dots, t_n$을 서로 다른 실수라고 할 때, $P_n$의 두 다항식 $p$와 $q$에 대해 다음과 같이 내적을 정의할 수 있습니다.
$$hp, qi = p(t_0)q(t_0) + p(t_1)q(t_1) + \dots + p(t_n)q(t_n) \quad (2)$$
이것이 내적을 정의하는지 확인하세요.

**예제 해설:**
1.  **대칭성:** `$$p(t_j)q(t_j) = q(t_j)p(t_j)$$`이므로 `$$hp, qi = hq, pi$$`는 쉽게 성립합니다.
2.  **선형성:** `$$hp+r, qi = (p(t_0)+r(t_0))q(t_0) + \dots = hp, qi + hr, qi$$` (여기서 $r$은 또 다른 다항식)로 성립합니다.
3.  **동차성:** `$$hcp, qi = (cp(t_0))q(t_0) + \dots = chp, qi$$`로 성립합니다.
4.  **양의 정부호성:**
    $$hp, pi = [p(t_0)]^2 + [p(t_1)]^2 + \dots + [p(t_n)]^2$$
    제곱의 합이므로 `$$\ge 0$$`임은 분명합니다.
    `$$hp, pi = 0$$`이 되려면 각 항이 모두 0이어야 합니다. 즉, `$$p(t_0)=0, p(t_1)=0, \dots, p(t_n)=0$$`이어야 합니다.
    다항식 $p$의 차수는 $n$보다 작거나 같은데, $n+1$개의 서로 다른 점에서 값이 0이 되는 다항식은 오직 **영다항식(zero polynomial)**뿐입니다. 따라서 $p = 0$ (영벡터)일 때만 `$$hp, pi = 0$$`이 됩니다.

모든 공리가 만족되므로, 식 (2)는 $P_n$ 위에 내적을 정의합니다.

---

### 🧠 [예제] 다항식 내적 계산
$V$를 $P_2$ 공간이라고 하고, 예제 2에서 정의된 내적을 사용하되, $t_0=0, t_1=1/2, t_2=1$이라고 합시다. 두 다항식 $p(t) = 12t^2$과 $q(t) = 2t-1$에 대해 `$$hp, qi$$`와 `$$hq, qi$$`를 계산하세요.

**예제 해설:**
내적 정의 (2)에 따라 각 $t_j$ 값에서의 함수 값을 계산하여 곱하고 더합니다.
먼저 $p(t)$와 $q(t)$의 각 $t_j$에서의 값을 구합니다:
*   $p(0) = 12(0)^2 = 0$
*   $p(1/2) = 12(1/2)^2 = 12(1/4) = 3$
*   $p(1) = 12(1)^2 = 12$
*   $q(0) = 2(0) - 1 = -1$
*   $q(1/2) = 2(1/2) - 1 = 1 - 1 = 0$
*   $q(1) = 2(1) - 1 = 1$

이제 `$$hp, qi$$`를 계산합니다:
$$hp, qi = p(0)q(0) + p(1/2)q(1/2) + p(1)q(1)$$
$$= (0)(-1) + (3)(0) + (12)(1)$$
$$= 0 + 0 + 12 = 12$$

다음으로 `$$hq, qi$$`를 계산합니다:
$$hq, qi = [q(0)]^2 + [q(1/2)]^2 + [q(1)]^2$$
$$= (-1)^2 + (0)^2 + (1)^2$$
$$= 1 + 0 + 1 = 2$$

## 🟦 Step 2: 길이, 거리, 직교성

내적 공간에서는 $R^n$에서와 유사하게 벡터의 길이, 벡터 간의 거리, 그리고 직교성을 정의할 수 있습니다.

### 📙 [정의] 길이(Norm), 거리(Distance), 직교성(Orthogonality)
내적 공간 $V$에서 내적을 `$$h\vec{u}, \vec{v}i$$`로 나타낼 때,
*   벡터 $\vec{v}$의 **길이(length)** 또는 **노름(norm)**은 스칼라 `$$||\vec{v}||$$`로 정의됩니다:
    $$||\vec{v}|| = \sqrt{h\vec{v}, \vec{v}i}$$
    동등하게 `$$||\vec{v}||^2 = h\vec{v}, \vec{v}i$$`입니다. (내적의 양의 정부호성 공리 때문에 `$$h\vec{v}, \vec{v}i \ge 0$$`이므로, 제곱근을 취하는 것이 가능합니다.)
*   **단위 벡터(unit vector)**는 길이가 1인 벡터입니다.
*   두 벡터 $\vec{u}$와 $\vec{v}$ 사이의 **거리(distance)**는 `$$||\vec{u} - \vec{v}||$$`로 정의됩니다.
*   두 벡터 $\vec{u}$와 $\vec{v}$는 `$$h\vec{u}, \vec{v}i = 0$$`일 때 **직교(orthogonal)**한다고 합니다.

---

### 🧠 [예제] 다항식의 길이 계산
예제 3에서 정의된 $P_2$ 내적 공간에서 다항식 $p(t) = 12t^2$와 $q(t) = 2t-1$의 길이를 계산하세요.

**예제 해설:**
예제 3에서 이미 `$$hp, pi$$` (아니었네요, `$$hq, qi$$`만 계산했습니다. `$$hp, pi$$`를 다시 계산해야 합니다.)와 `$$hq, qi$$` 값을 구했습니다.

먼저 `$$p(t) = 12t^2$$`의 길이 `$$||p||$$`를 계산합니다:
`$$||p||^2 = hp, pi = [p(0)]^2 + [p(1/2)]^2 + [p(1)]^2$$`
`$$p(0)=0, p(1/2)=3, p(1)=12$$` 이므로,
`$$||p||^2 = 0^2 + 3^2 + 12^2 = 0 + 9 + 144 = 153$$`
따라서 `$$||p|| = \sqrt{153}$$` 입니다.

다음으로 `$$q(t) = 2t-1$$`의 길이 `$$||q||$$`를 계산합니다:
예제 3에서 `$$hq, qi = 2$$`로 이미 계산했습니다.
따라서 `$$||q|| = \sqrt{hq, qi} = \sqrt{2}$$` 입니다.

## 🟦 Step 3: 그람-슈미트 과정

내적 공간에서도 $R^n$과 마찬가지로 직교 기저를 구성하는 데 **그람-슈미트 과정(Gram–Schmidt process)**을 사용할 수 있습니다. 이 과정은 유한 차원 내적 공간의 부분 공간에 대해 직교 기저의 존재를 확립해줍니다.

### 🧠 [예제] 다항식 공간 $P_2$에서 직교 기저 생성
$V$를 $P_4$ 공간이라고 하고, 예제 2의 내적을 사용하되, 이번에는 다항식을 $-2, -1, 0, 1, 2$에서 평가하는 내적이라고 합시다. $P_2$를 $V$의 부분 공간으로 간주하고, 다항식 $1, t, t^2$에 그람-슈미트 과정을 적용하여 $P_2$의 직교 기저를 생성하세요.

**예제 해설:**
내적은 각 다항식을 $-2, -1, 0, 1, 2$에서 평가한 값에 따라 결정됩니다. 각 다항식의 값을 $R^5$ 벡터로 표현해봅시다.
*   다항식 `$$p_0(t) = 1$$`: 값 벡터 `$$\begin{pmatrix} 1 \\ 1 \\ 1 \\ 1 \\ 1 \end{pmatrix}$$`
*   다항식 `$$p_1(t) = t$$`: 값 벡터 `$$\begin{pmatrix} -2 \\ -1 \\ 0 \\ 1 \\ 2 \end{pmatrix}$$`
*   다항식 `$$p_2(t) = t^2$$`: 값 벡터 `$$\begin{pmatrix} 4 \\ 1 \\ 0 \\ 1 \\ 4 \end{pmatrix}$$`

두 다항식의 내적은 이들의 $R^5$ 값 벡터들의 표준 내적과 같습니다.
**1단계:** 첫 번째 기저 벡터 `$$\vec{p_0}$$`를 `$$\vec{q_0}$$`로 정합니다. `$$q_0(t) = 1$$`.
**2단계:** `$$\vec{p_1}$$`을 `$$\vec{q_0}$$`에 직교하는 벡터로 만듭니다.
`$$q_1(t) = p_1(t) - \text{proj}_{\text{Span}\{q_0\}} p_1 = p_1(t) - \frac{hp_1, q_0i}{hq_0, q_0i} q_0(t)$$`
먼저 내적들을 계산합니다:
`$$hp_1, q_0i = h t, 1 i = (-2)(1) + (-1)(1) + (0)(1) + (1)(1) + (2)(1) = -2 - 1 + 0 + 1 + 2 = 0$$`
`$$hq_0, q_0i = h 1, 1 i = 1^2 + 1^2 + 1^2 + 1^2 + 1^2 = 5$$`
`$$hp_1, q_0i = 0$$`이므로, `$$p_1(t)$$`는 이미 `$$q_0(t)$$`와 직교합니다! 따라서 `$$q_1(t) = t$$`로 그대로 둡니다.

**3단계:** `$$\vec{p_2}$$`를 `$$\text{Span}\{q_0, q_1\}$$ (즉, Span`$\{1, t\}$)에 직교하는 벡터로 만듭니다.
`$$q_2(t) = p_2(t) - \text{proj}_{\text{Span}\{q_0, q_1\}} p_2 = p_2(t) - \frac{hp_2, q_0i}{hq_0, q_0i} q_0(t) - \frac{hp_2, q_1i}{hq_1, q_1i} q_1(t)$$`
먼저 필요한 내적들을 계산합니다:
`$$hp_2, q_0i = h t^2, 1 i = (-2)^2(1) + (-1)^2(1) + (0)^2(1) + (1)^2(1) + (2)^2(1) = 4+1+0+1+4 = 10$$`
`$$hq_0, q_0i = 5$$` (위에서 계산)
`$$hp_2, q_1i = h t^2, t i = (-2)^2(-2) + (-1)^2(-1) + (0)^2(0) + (1)^2(1) + (2)^2(2) = -8 - 1 + 0 + 1 + 8 = 0$$`
`$$hq_1, q_1i = h t, t i = (-2)^2 + (-1)^2 + 0^2 + 1^2 + 2^2 = 4+1+0+1+4 = 10$$`

이제 대입하여 `$$q_2(t)$$`를 계산합니다:
`$$q_2(t) = t^2 - \frac{10}{5} (1) - \frac{0}{10} (t)$$`
`$$q_2(t) = t^2 - 2$$`

따라서 $P_2$의 직교 기저는 `{1, t, t^2 - 2}`입니다.
각 기저 다항식의 값 벡터는 다음과 같습니다:
*   `$$q_0(t) = 1$$`: `$$\begin{pmatrix} 1 \\ 1 \\ 1 \\ 1 \\ 1 \end{pmatrix}$$`
*   `$$q_1(t) = t$$`: `$$\begin{pmatrix} -2 \\ -1 \\ 0 \\ 1 \\ 2 \end{pmatrix}$$`
*   `$$q_2(t) = t^2 - 2$$`: `$$\begin{pmatrix} (-2)^2-2 \\ (-1)^2-2 \\ 0^2-2 \\ 1^2-2 \\ 2^2-2 \end{pmatrix} = \begin{pmatrix} 2 \\ -1 \\ -2 \\ -1 \\ 2 \end{pmatrix}$$`

## 🟦 Step 4: 최적 근사

응용 수학에서 흔히 접하는 문제 중 하나는 특정 벡터 공간 $V$에 있는 함수 $f$를 $V$의 지정된 부분 공간 $W$에 있는 함수 $g$로 근사하는 것입니다. 이러한 근사의 "정확성"은 `$$||f-g||$$`가 어떻게 정의되는지에 달려 있습니다. 내적 공간에서는 함수 $f$에 대한 $W$ 내의 **최적 근사(best approximation)**가 바로 $f$를 부분 공간 $W$에 대한 **정사영(orthogonal projection)**으로 정의됩니다.

### 🧠 [예제] 다항식의 최적 근사
예제 5에서 사용된 $P_4$ 내적 공간 (평가점: $-2, -1, 0, 1, 2$)에서, 부분 공간 $P_2$에 대한 직교 기저 $p_0, p_1, p_2$가 `{1, t, t^2-2}`임을 알았습니다. 다항식 `$$p(t) = 5 - \frac{1}{2}t^4$$`에 대한 $P_2$ 내에서의 최적 근사를 찾으세요.

**예제 해설:**
최적 근사는 정사영 `$$\hat{p} = \text{proj}_{P_2} p$$`로 주어집니다.
직교 기저 $q_0, q_1, q_2$를 사용하면 정사영은 다음 공식으로 계산됩니다:
`$$\hat{p} = \frac{hp, q_0i}{hq_0, q_0i} q_0 + \frac{hp, q_1i}{hq_1, q_1i} q_1 + \frac{hp, q_2i}{hq_2, q_2i} q_2$$`

먼저 다항식 $p(t)$의 값 벡터를 구합니다:
`$$p(-2) = 5 - \frac{1}{2}(-2)^4 = 5 - \frac{1}{2}(16) = 5 - 8 = -3$$`
`$$p(-1) = 5 - \frac{1}{2}(-1)^4 = 5 - \frac{1}{2} = \frac{9}{2}$$`
`$$p(0) = 5 - \frac{1}{2}(0)^4 = 5$$`
`$$p(1) = 5 - \frac{1}{2}(1)^4 = 5 - \frac{1}{2} = \frac{9}{2}$$`
`$$p(2) = 5 - \frac{1}{2}(2)^4 = 5 - \frac{1}{2}(16) = 5 - 8 = -3$$`
값 벡터: `$$\begin{pmatrix} -3 \\ 9/2 \\ 5 \\ 9/2 \\ -3 \end{pmatrix}$$`

이제 필요한 내적들을 계산합니다 (예제 5에서 `$$hq_0, q_0i = 5$$`, `$$hq_1, q_1i = 10$$`, `$$hq_2, q_2i$$`는 다시 계산):
`$$hq_2, q_2i = h t^2-2, t^2-2 i = (2)^2 + (-1)^2 + (-2)^2 + (-1)^2 + (2)^2 = 4+1+4+1+4 = 14$$`

*   `$$hp, q_0i = (-3)(1) + (9/2)(1) + (5)(1) + (9/2)(1) + (-3)(1) = -3 + 4.5 + 5 + 4.5 - 3 = 8$$`
*   `$$hp, q_1i = (-3)(-2) + (9/2)(-1) + (5)(0) + (9/2)(1) + (-3)(2) = 6 - 4.5 + 0 + 4.5 - 6 = 0$$`
*   `$$hp, q_2i = (-3)(2) + (9/2)(-1) + (5)(-2) + (9/2)(-1) + (-3)(2) = -6 - 4.5 - 10 - 4.5 - 6 = -31$$`

이제 정사영 공식을 사용하여 최적 근사를 계산합니다:
`$$\hat{p} = \frac{8}{5} q_0 + \frac{0}{10} q_1 + \frac{-31}{14} q_2$$`
`$$\hat{p} = \frac{8}{5} (1) + 0 (t) - \frac{31}{14} (t^2 - 2)$$`
`$$\hat{p}(t) = \frac{8}{5} - \frac{31}{14} (t^2 - 2)$$`

이 다항식 `$$\hat{p}(t)$$`는 $-2, -1, 0, 1, 2$에서 측정했을 때, $P_2$의 모든 다항식 중에서 $p(t)$에 가장 가까운 다항식입니다.

## 🟦 Step 5: 중요한 두 가지 부등식

내적 공간의 성질을 통해 두 가지 매우 중요한 부등식을 증명할 수 있습니다. 이 부등식들은 다양한 수학 분야에서 유용하게 사용됩니다.

### 📘 [정리] 코시-슈바르츠 부등식 (Cauchy–Schwarz Inequality)
내적 공간 $V$의 모든 벡터 $\vec{u}, \vec{v}$에 대해 다음이 성립합니다:
$$|h\vec{u}, \vec{v}i| \le ||\vec{u}|| \cdot ||\vec{v}|| \quad (4)$$
여기서 `$$|h\vec{u}, \vec{v}i|$$`는 내적 값의 절댓값을 의미합니다.

**정리의 의미:**
이 부등식은 두 벡터의 내적의 절댓값이 각 벡터 길이의 곱보다 크지 않다는 것을 말해줍니다. $R^n$에서는 `$$|\vec{u} \cdot \vec{v}| = ||\vec{u}|| \cdot ||\vec{v}|| |\cos\theta|$$`이므로, `$$|\cos\theta| \le 1$$`인 것과 같은 의미를 가집니다. 즉, 내적 공간에서 "각도" 개념을 일반화하는 데 중요한 기반이 됩니다.

**정리의 증명 아이디어:**
$\vec{u} = \vec{0}$인 경우는 자명하게 성립합니다. $\vec{u} \ne \vec{0}$일 때, $\vec{v}$를 $\vec{u}$가 생성하는 부분 공간 $W = \text{Span}\{\vec{u}\}$에 정사영시켜봅니다.
정사영 `$$\text{proj}_W \vec{v} = \frac{h\vec{v}, \vec{u}i}{h\vec{u}, \vec{u}i} \vec{u}$$`의 길이는 `$$||\text{proj}_W \vec{v}|| = \left| \frac{h\vec{v}, \vec{u}i}{h\vec{u}, \vec{u}i} \right| ||\vec{u}||$$` 입니다.
이것을 간단히 정리하면 `$$||\text{proj}_W \vec{v}|| = \frac{|h\vec{v}, \vec{u}i|}{h\vec{u}, \vec{u}i} ||\vec{u}|| = \frac{|h\vec{u}, \vec{v}i|}{ ||\vec{u}||^2 } ||\vec{u}|| = \frac{|h\vec{u}, \vec{v}i|}{ ||\vec{u}|| }$$`가 됩니다.
피타고라스 정리에 따르면 `$$||\vec{v}||^2 = ||\text{proj}_W \vec{v}||^2 + ||\vec{v} - \text{proj}_W \vec{v}||^2$$`이므로, `$$||\text{proj}_W \vec{v}|| \le ||\vec{v}||$$`는 항상 성립합니다.
따라서 `$$\frac{|h\vec{u}, \vec{v}i|}{ ||\vec{u}|| } \le ||\vec{v}||$$`이고, 양변에 `$$||\vec{u}||$$`를 곱하면 `$$|h\vec{u}, \vec{v}i| \le ||\vec{u}|| \cdot ||\vec{v}||$$`를 얻습니다.

### 📘 [정리] 삼각 부등식 (Triangle Inequality)
내적 공간 $V$의 모든 벡터 $\vec{u}, \vec{v}$에 대해 다음이 성립합니다:
$$||\vec{u} + \vec{v}|| \le ||\vec{u}|| + ||\vec{v}||$$

**정리의 의미:**
이 부등식은 $R^n$에서 삼각형의 두 변의 길이의 합이 나머지 한 변의 길이보다 크거나 같다는 기하학적 의미를 내적 공간으로 확장한 것입니다.

**정리의 증명 아이디어:**
`$$||\vec{u} + \vec{v}||^2$$`부터 시작하여 내적의 공리와 코시-슈바르츠 부등식을 사용합니다.
$$||\vec{u} + \vec{v}||^2 = h\vec{u} + \vec{v}, \vec{u} + \vec{v}i$$
내적의 선형성과 대칭성 공리를 이용해 전개하면:
$$= h\vec{u}, \vec{u}i + h\vec{u}, \vec{v}i + h\vec{v}, \vec{u}i + h\vec{v}, \vec{v}i$$
$$= h\vec{u}, \vec{u}i + 2h\vec{u}, \vec{v}i + h\vec{v}, \vec{v}i$$
이제 `$$h\vec{u}, \vec{u}i = ||\vec{u}||^2$$`와 `$$h\vec{v}, \vec{v}i = ||\vec{v}||^2$$`를 대입합니다:
$$= ||\vec{u}||^2 + 2h\vec{u}, \vec{v}i + ||\vec{v}||^2$$
코시-슈바르츠 부등식 `$$h\vec{u}, \vec{v}i \le |h\vec{u}, \vec{v}i|$$`를 적용하면:
$$\le ||\vec{u}||^2 + 2|h\vec{u}, \vec{v}i| + ||\vec{v}||^2$$
다시 코시-슈바르츠 부등식 `$$|h\vec{u}, \vec{v}i| \le ||\vec{u}|| \cdot ||\vec{v}||$$`를 적용하면:
$$\le ||\vec{u}||^2 + 2||\vec{u}|| \cdot ||\vec{v}|| + ||\vec{v}||^2$$
이것은 완전 제곱식으로 묶입니다:
$$= (||\vec{u}|| + ||\vec{v}||)^2$$
따라서 `$$||\vec{u} + \vec{v}||^2 \le (||\vec{u}|| + ||\vec{v}||)^2$$`이므로, 양변에 제곱근을 취하면 (길이는 항상 양수이므로):
$$||\vec{u} + \vec{v}|| \le ||\vec{u}|| + ||\vec{v}||$$
이것으로 삼각 부등식이 증명됩니다.

## 🟦 Step 6: 연속 함수 공간 $C[a, b]$의 내적 (미적분학 지식 필요)

아마도 응용 분야에서 가장 널리 사용되는 내적 공간은 구간 `$$[a, b]$$`에서 정의된 모든 연속 함수들의 벡터 공간 `$$C[a, b]$$`일 것입니다. 이 공간에 내적을 정의하는 방법을 알아봅시다.

이전 예제에서 다항식 공간 $P_n$에 대해 $n+1$개의 점 `$$t_0, \dots, t_n$$`에서의 함수 값을 이용하여 내적을 정의했습니다. 하지만 이 내적은 선택된 몇몇 점에서만 함수의 거동을 포착합니다. 만약 $n$을 무한히 크게 하여 `$$[a, b]$$` 구간에 무한히 많은 점을 고려한다면 어떨까요?

구간 `$$[a, b]$$`를 $n+1$개의 작은 부분 구간으로 나누고, 각 부분 구간에서 임의의 점 `$$t_j$$`를 선택하여 다항식 내적의 정의를 변형해봅시다.
`$$hp, qi = \frac{1}{n+1} \sum_{j=0}^{n} p(t_j)q(t_j)$$`
여기서 `$$\frac{1}{n+1} = \frac{\Delta t}{b-a}$$`이므로 (여기서 `$$\Delta t = (b-a)/(n+1)$$`), 위 식은 다음과 같이 쓸 수 있습니다:
`$$hp, qi = \frac{1}{b-a} \sum_{j=0}^{n} p(t_j)q(t_j) \Delta t$$`
이제 $n$을 무한히 크게 하면, 이 합은 리만 합(Riemann sum)의 형태로 정적분(definite integral)으로 수렴합니다. 따라서 `$$p(t)q(t)$$`의 구간 `$$[a, b]$$`에서의 "평균값" 형태를 얻게 됩니다.
`$$\frac{1}{b-a} \int_{a}^{b} p(t)q(t) dt$$`
이 양은 모든 연속 함수에 대해 정의될 수 있으며, 내적의 모든 성질을 만족합니다. 스케일링 인자 `$$\frac{1}{b-a}$$`는 필수적이지 않으므로 종종 생략됩니다.

### 📙 [정의] 연속 함수 공간 $C[a, b]$의 내적
`$$C[a, b]$$`의 두 함수 $f, g$에 대해 다음과 같이 내적을 정의합니다.
$$hf, gi = \int_{a}^{b} f(t)g(t) dt \quad (5)$$

---

### 🧠 [예제] $C[a, b]$에서의 내적 확인
`$$C[a, b]$$` 공간에서 위의 정의 (5)가 내적을 정의함을 보이세요.

**예제 해설:**
내적의 공리들은 정적분의 기본 성질로부터 쉽게 따라 나옵니다.
1.  **대칭성:** `$$hf, gi = \int_a^b f(t)g(t) dt = \int_a^b g(t)f(t) dt = hg, fi$$` (곱셈은 교환법칙 성립)
2.  **선형성:** `$$hf+h, gi = \int_a^b (f(t)+h(t))g(t) dt = \int_a^b f(t)g(t) dt + \int_a^b h(t)g(t) dt = hf, gi + hh, gi$$` (적분은 선형성 성립)
3.  **동차성:** `$$hcf, gi = \int_a^b (cf(t))g(t) dt = c \int_a^b f(t)g(t) dt = chf, gi$$` (상수는 적분 밖으로 나갈 수 있음)
4.  **양의 정부호성:**
    `$$hf, fi = \int_a^b [f(t)]^2 dt$$`
    함수 `$$[f(t)]^2$$`은 `$$[a, b]$$`에서 연속이고 항상 `$$\ge 0$$`입니다. 따라서 이 함수의 적분은 항상 `$$\ge 0$$`입니다.
    `$$hf, fi = 0$$`이 되려면, `$$[f(t)]^2$$`이 `$$[a, b]$$` 구간 전체에서 항등적으로 0이어야만 합니다. 즉, $f(t)$가 `$$[a, b]$$` 위에서 영함수(zero function)일 때만 `$$hf, fi = 0$$`이 됩니다.

모든 공리가 만족되므로, 식 (5)는 `$$C[a, b]$$` 위에 내적을 정의합니다.

### 🧠 [예제] $C[0, 1]$에서 직교 기저 생성
$V$를 예제 7의 내적을 가진 공간 `$$C[0, 1]$$`이라고 하고, $W$를 다항식 $p_1(t)=1, p_2(t)=2t-1, p_3(t)=12t^2$에 의해 생성되는 부분 공간이라고 합시다. 그람-슈미트 과정을 사용하여 $W$의 직교 기저를 찾으세요.

**예제 해설:**
**1단계:** `$$q_1(t) = p_1(t) = 1$$`로 설정합니다.
**2단계:** `$$p_2(t) = 2t-1$$`을 `$$\text{Span}\{q_1\}$$에 직교하는 `$$q_2(t)$$`로 만듭니다.
`$$q_2(t) = p_2(t) - \frac{hp_2, q_1i}{hq_1, q_1i} q_1(t)$$`
내적을 계산합니다:
`$$hp_2, q_1i = \int_0^1 (2t-1)(1) dt = [t^2 - t]_0^1 = (1^2-1) - (0^2-0) = 0$$`
`$$hq_1, q_1i = \int_0^1 (1)(1) dt = [t]_0^1 = 1$$`
`$$hp_2, q_1i = 0$$`이므로, `$$p_2(t)$$`는 이미 `$$q_1(t)$$`와 직교합니다.
따라서 `$$q_2(t) = p_2(t) = 2t-1$$`로 둡니다.

**3단계:** `$$p_3(t) = 12t^2$$`을 `$$\text{Span}\{q_1, q_2\}$$에 직교하는 `$$q_3(t)$$`로 만듭니다.
`$$q_3(t) = p_3(t) - \frac{hp_3, q_1i}{hq_1, q_1i} q_1(t) - \frac{hp_3, q_2i}{hq_2, q_2i} q_2(t)$$`
필요한 내적들을 계산합니다:
`$$hp_3, q_1i = \int_0^1 12t^2(1) dt = [4t^3]_0^1 = 4$$`
`$$hq_1, q_1i = 1$$` (위에서 계산)
`$$hp_3, q_2i = \int_0^1 12t^2(2t-1) dt = \int_0^1 (24t^3 - 12t^2) dt = [6t^4 - 4t^3]_0^1 = (6-4) - (0-0) = 2$$`
`$$hq_2, q_2i = \int_0^1 (2t-1)^2 dt = \int_0^1 (4t^2 - 4t + 1) dt = [\frac{4}{3}t^3 - 2t^2 + t]_0^1 = (\frac{4}{3} - 2 + 1) - 0 = \frac{1}{3}$$`

이제 `$$q_3(t)$$`를 계산합니다:
`$$\text{proj}_{W_2} p_3 = \frac{4}{1} q_1(t) + \frac{2}{1/3} q_2(t) = 4q_1(t) + 6q_2(t)$$`
`$$q_3(t) = p_3(t) - (4q_1(t) + 6q_2(t))$$`
`$$q_3(t) = 12t^2 - 4(1) - 6(2t-1)$$`
`$$q_3(t) = 12t^2 - 4 - 12t + 6$$`
`$$q_3(t) = 12t^2 - 12t + 2$$`

따라서 부분 공간 $W$의 직교 기저는 `{1, 2t-1, 12t^2-12t+2}`입니다.

| 개념 | 설명 | 수식/예시 |
|---|---|---|
| **내적 공간 (Inner Product Space)** | 길이, 거리, 직교성을 일반화한 벡터 공간. 내적은 4가지 공리를 만족. | 1. `$$h\vec{u}, \vec{v}i = h\vec{v}, \vec{u}i$$`<br>2. `$$h\vec{u}+\vec{v}, \vec{w}i = h\vec{u}, \vec{w}i + h\vec{v}, \vec{w}i$$`<br>3. `$$hc\vec{u}, \vec{v}i = ch\vec{u}, \vec{v}i$$`<br>4. `$$h\vec{u}, \vec{u}i \ge 0$$` (`$$=0 \iff \vec{u}=\vec{0}$$`) |

| **최적 근사** | 부분 공간 $W$에서 벡터 $\vec{v}$에 가장 가까운 벡터는 $\vec{v}$의 $W$로의 정사영. | `$$\text{proj}_W \vec{v} = \sum_{k=1}^{p} \frac{h\vec{v}, \vec{u}_k i}{h\vec{u}_k, \vec{u}_k i} \vec{u}_k$$` (여기서 `$$\{\vec{u}_k\}$$`는 $W$의 직교 기저) |
| **코시-슈바르츠 부등식** | 내적과 길이 사이의 관계를 나타내는 중요한 부등식. | `$$|h\vec{u}, \vec{v}i| \le ||\vec{u}|| \cdot ||\vec{v}||$$` |
| **삼각 부등식** | 세 벡터로 이루어진 "삼각형"의 길이 관계를 나타내는 부등식. | `$$||\vec{u} + \vec{v}|| \le ||\vec{u}|| + ||\vec{v}||$$` |
| **$C[a, b]$ 내적** | 연속 함수 공간에서 적분을 이용한 내적 정의. | `$$hf, gi = \int_{a}^{b} f(t)g(t) dt$$` |

### 🔸 연습문제1  
벡터 공간 $\mathbb{R}^3$에 대해 두 벡터 $\mathbf{u} = (u_1, u_2, u_3)$와 $\mathbf{v} = (v_1, v_2, v_3)$의 내적을 다음과 같이 정의합니다:
$$
\langle \mathbf{u}, \mathbf{v} \rangle = 2u_1v_1 + 3u_2v_2 + u_3v_3
$$
이 정의가 내적 공간의 4가지 공리(Axiom)를 모두 만족하여 $\mathbb{R}^3$의 내적을 정의하는지 보이시오.

{: .answer-title }
> 정답 보기  
>  
> 정답:  
> 1. **Axiom 1 (대칭성):**  
>    $\langle \mathbf{u}, \mathbf{v} \rangle = 2u_1v_1 + 3u_2v_2 + u_3v_3$  
>    $= 2v_1u_1 + 3v_2u_2 + v_3u_3$ (실수의 곱셈은 교환법칙이 성립하므로)  
>    $= \langle \mathbf{v}, \mathbf{u} \rangle$.  
>    따라서 Axiom 1이 만족됩니다.
>  
> 2. **Axiom 2 (덧셈에 대한 선형성):**  
>    $\mathbf{w} = (w_1, w_2, w_3)$라고 하면,  
>    $\langle \mathbf{u} + \mathbf{v}, \mathbf{w} \rangle = 2(u_1+v_1)w_1 + 3(u_2+v_2)w_2 + (u_3+v_3)w_3$  
>    $= (2u_1w_1 + 2v_1w_1) + (3u_2w_2 + 3v_2w_2) + (u_3w_3 + v_3w_3)$  
>    $= (2u_1w_1 + 3u_2w_2 + u_3w_3) + (2v_1w_1 + 3v_2w_2 + v_3w_3)$  
>    $= \langle \mathbf{u}, \mathbf{w} \rangle + \langle \mathbf{v}, \mathbf{w} \rangle$.  
>    따라서 Axiom 2가 만족됩니다.
>  
> 3. **Axiom 3 (스칼라 곱에 대한 선형성):**  
>    $c$가 스칼라일 때,  
>    $\langle c\mathbf{u}, \mathbf{v} \rangle = 2(cu_1)v_1 + 3(cu_2)v_2 + (cu_3)v_3$  
>    $= c(2u_1v_1) + c(3u_2v_2) + c(u_3v_3)$  
>    $= c(2u_1v_1 + 3u_2v_2 + u_3v_3) = c\langle \mathbf{u}, \mathbf{v} \rangle$.  
>    따라서 Axiom 3이 만족됩니다.
>  
> 4. **Axiom 4 (양의 정부호성):**  
>    $\langle \mathbf{u}, \mathbf{u} \rangle = 2u_1^2 + 3u_2^2 + u_3^2$.  
>    $u_1^2 \ge 0$, $u_2^2 \ge 0$, $u_3^2 \ge 0$ 이므로 $2u_1^2 + 3u_2^2 + u_3^2 \ge 0$ 입니다. 즉, $\langle \mathbf{u}, \mathbf{u} \rangle \ge 0$.  
>    또한, $2u_1^2 + 3u_2^2 + u_3^2 = 0$이 되려면 각 항이 모두 0이어야 하므로 $u_1^2=0, u_2^2=0, u_3^2=0$, 즉 $u_1=0, u_2=0, u_3=0$이어야 합니다. 이는 $\mathbf{u} = \mathbf{0}$을 의미합니다.  
>    따라서 Axiom 4가 만족됩니다.  
>  
> 해설: 위에서 보인 바와 같이, 주어진 정의는 내적 공간의 4가지 공리를 모두 만족하므로 $\mathbb{R}^3$의 내적을 정의합니다.

### 🔸 연습문제2  
$P_1$을 차수가 1 이하인 다항식들의 벡터 공간이라고 하고, 내적은 $t_0=0$과 $t_1=1$에서 다항식의 값을 평가하여 다음과 같이 정의합니다. (Example 2 참고)
$$
\langle p, q \rangle = p(0)q(0) + p(1)q(1)
$$
다음 다항식 $p(t) = 2t+1$과 $q(t) = t-1$에 대하여 다음을 계산하시오.
a. $\langle p, q \rangle$
b. $\|p\|$
c. $p$와 $q$는 서로 직교하는가?

{: .answer-title }
> 정답 보기  
>  
> 정답:  
> 먼저 다항식 $p(t)$와 $q(t)$의 $t=0$과 $t=1$에서의 값을 계산합니다.  
> $p(0) = 2(0)+1 = 1$  
> $p(1) = 2(1)+1 = 3$  
> $q(0) = 0-1 = -1$  
> $q(1) = 1-1 = 0$  
>  
> a. $\langle p, q \rangle$ 계산:  
>    $\langle p, q \rangle = p(0)q(0) + p(1)q(1) = (1)(-1) + (3)(0) = -1 + 0 = -1$.  
>  
> b. $\|p\|$ 계산:  
>    $\|p\| = \sqrt{\langle p, p \rangle}$  
>    $\langle p, p \rangle = p(0)p(0) + p(1)p(1) = (1)^2 + (3)^2 = 1 + 9 = 10$.  
>    따라서 $\|p\| = \sqrt{10}$.  
>  
> c. $p$와 $q$의 직교 여부 판단:  
>    $p$와 $q$가 직교하려면 $\langle p, q \rangle = 0$이어야 합니다.  
>    a.에서 계산한 $\langle p, q \rangle = -1$ 이므로, $p$와 $q$는 직교하지 않습니다.  
>  
> 해설: 주어진 내적 정의에 따라 각 값을 계산합니다. 두 벡터가 직교하려면 내적이 0이어야 합니다.

### 🔸 연습문제3  
$\mathbb{R}^2$에 Example 1에서 정의된 내적 $\langle \mathbf{u}, \mathbf{v} \rangle = 4u_1v_1 + 5u_2v_2$를 사용합니다.  
두 벡터 $\mathbf{u} = (1, 2)$와 $\mathbf{v} = (3, 1)$에 대하여 코시-슈바르츠 부등식(Cauchy-Schwarz Inequality) $|\langle \mathbf{u}, \mathbf{v} \rangle| \le \|\mathbf{u}\| \|\mathbf{v}\|$가 성립함을 보이시오.

{: .answer-title }
> 정답 보기  
>  
> 정답:  
> 먼저 내적 $\langle \mathbf{u}, \mathbf{v} \rangle$와 노름 $\|\mathbf{u}\|$, $\|\mathbf{v}\|$를 계산합니다.  
>  
> 1. $\langle \mathbf{u}, \mathbf{v} \rangle$ 계산:  
>    $\langle \mathbf{u}, \mathbf{v} \rangle = 4(u_1v_1) + 5(u_2v_2) = 4(1)(3) + 5(2)(1) = 12 + 10 = 22$.  
>  
> 2. $\|\mathbf{u}\|$ 계산:  
>    $\|\mathbf{u}\|^2 = \langle \mathbf{u}, \mathbf{u} \rangle = 4(u_1u_1) + 5(u_2u_2) = 4(1)^2 + 5(2)^2 = 4(1) + 5(4) = 4 + 20 = 24$.  
>    $\|\mathbf{u}\| = \sqrt{24} = 2\sqrt{6}$.  
>  
> 3. $\|\mathbf{v}\|$ 계산:  
>    $\|\mathbf{v}\|^2 = \langle \mathbf{v}, \mathbf{v} \rangle = 4(v_1v_1) + 5(v_2v_2) = 4(3)^2 + 5(1)^2 = 4(9) + 5(1) = 36 + 5 = 41$.  
>    $\|\mathbf{v}\| = \sqrt{41}$.  
>  
> 이제 코시-슈바르츠 부등식 $|\langle \mathbf{u}, \mathbf{v} \rangle| \le \|\mathbf{u}\| \|\mathbf{v}\|$의 양변을 비교합니다.  
> 부등식의 좌변: $|\langle \mathbf{u}, \mathbf{v} \rangle| = |22| = 22$.  
> 부등식의 우변: $\|\mathbf{u}\| \|\mathbf{v}\| = (2\sqrt{6})(\sqrt{41}) = 2\sqrt{6 \times 41} = 2\sqrt{246}$.  
>  
> $22$와 $2\sqrt{246}$를 비교하기 위해 양변을 제곱합니다.  
> $22^2 = 484$.  
> $(2\sqrt{246})^2 = 4 \times 246 = 984$.  
>  
> $484 \le 984$ 이므로, $22 \le 2\sqrt{246}$가 성립합니다.  
> 따라서 코시-슈바르츠 부등식 $|\langle \mathbf{u}, \mathbf{v} \rangle| \le \|\mathbf{u}\| \|\mathbf{v}\|$는 주어진 벡터와 내적에 대해 성립합니다.  
>  
> 해설: 정의된 내적을 사용하여 $\langle \mathbf{u}, \mathbf{v} \rangle$, $\|\mathbf{u}\|$, $\|\mathbf{v}\|$를 각각 계산한 후, 코시-슈바르츠 부등식의 양변을 비교하여 성립함을 보입니다.
