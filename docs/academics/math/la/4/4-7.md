# 📘 Chapter 4-7 – Digital Signal Processing

## 🎯 목표
이 단원에서는 디지털 신호 처리(DSP)의 기본 개념을 탐구하고, 시간에 따라 수집되는 데이터를 '이산 시간 신호'로 이해하는 방법을 배웁니다. 선형 대수학의 관점에서 신호 공간과 그 부분 공간의 특성을 이해하고, 신호를 처리하고 변형하는 데 사용되는 '선형 시불변 변환(LTI 변환)'의 중요한 역할을 학습합니다. 궁극적으로 신호 데이터를 효과적으로 저장하고 처리하는 방법을 익히는 것이 목표입니다.

---

## 🟦 Step 1: 이산 시간 신호의 이해

우리가 일상에서 접하는 많은 데이터는 시간이 지남에 따라 연속적으로 변하는 것처럼 보이지만, 컴퓨터나 디지털 시스템에서는 특정 시간 간격으로 데이터를 샘플링하여 처리합니다. 이렇게 특정 시점에서 측정되거나 샘플링된 데이터의 연속을 '이산 시간 신호'라고 부릅니다. 이는 마치 일기 예보가 매일 정해진 시각에 온도를 측정하여 기록하는 것과 비슷합니다.

### 📙 [정의] 이산 시간 신호 공간 ($$S$$)
'이산 시간 신호'는 모든 정수 $$k$$에 대해 첨자 $$k$$를 갖는 숫자들의 무한 수열 $$f y_k g$$로 정의됩니다. 이 모든 이산 시간 신호들의 집합을 '이산 시간 신호 공간($$S$$)'이라고 합니다.

예를 들어, 주식 시장의 일별 종가, 음파의 디지털 샘플, 특정 기기의 작동 로그 등이 모두 이산 시간 신호로 간주될 수 있습니다.

### 🧠 [예제] 다양한 이산 시간 신호
아래 표는 몇 가지 기본적인 이산 시간 신호들을 보여줍니다. 이 신호들은 나중에 LTI 변환을 이해하는 데 중요한 역할을 합니다.

| 이름 | 기호 | 벡터 표현 | 공식 정의 |
|---|---|---|---|
| 델타(delta) | $$\delta$$ | $$\dots, 0, 0, \underline{1}, 0, 0, \dots$$ | $$d_k = \begin{cases} 1 & \text{if } k=0 \\ 0 & \text{if } k \neq 0 \end{cases}$$ |
| 단위 계단(unit step) | $$u$$ | $$\dots, 0, 0, \underline{1}, 1, 1, \dots$$ | $$u_k = \begin{cases} 1 & \text{if } k \ge 0 \\ 0 & \text{if } k < 0 \end{cases}$$ |
| 상수(constant) | $$c$$ | $$\dots, 1, 1, \underline{1}, 1, 1, \dots$$ | $$c_k = 1$$ |
| 교대(alternating) | $$\alpha$$ | $$\dots, -1, 1, \underline{-1}, 1, -1, \dots$$ | $$a_k = (-1)^k$$ |
| 지수(exponential) | $$e_c$$ | $$\dots, c^{-2}, c^{-1}, \underline{c^0}, c^1, c^2, \dots$$ | $$e_k = c^k$$ |

**참고:** 밑줄이 그어진 부분은 $$k=0$$일 때의 값을 나타냅니다.

## 🟦 Step 2: 선형 시불변 변환 (LTI 변환)

디지털 신호 처리에서 가장 중요하게 사용되는 도구 중 하나는 '선형 시불변 변환(LTI 변환)'입니다. 이 변환들은 신호를 필터링하거나, 부드럽게 만들거나, 새로운 신호를 생성하는 데 사용됩니다. LTI 변환은 이름에서 알 수 있듯이 '선형성'과 '시불변성'이라는 두 가지 핵심 속성을 가집니다.

### 📙 [정의] 선형 시불변 (LTI) 변환
신호 공간 $$S$$에서 $$S$$로의 변환 $$T: S \to S$$가 다음 세 가지 조건을 만족하면 '선형 시불변 변환'이라고 합니다.

(i) **선형성 (덧셈에 대한 분배)**: 모든 신호 $$f x_k g$$와 $$f y_k g$$에 대해 다음이 성립합니다:
$$
T(f x_k + y_k g) = T(f x_k g) + T(f y_k g)
$$
(ii) **선형성 (스칼라 곱에 대한 분배)**: 모든 스칼라 $$c$$와 모든 신호 $$f x_k g$$에 대해 다음이 성립합니다:
$$
T(c f x_k g) = c T(f x_k g)
$$
(iii) **시불변성 (Time Invariance)**: 만약 $$T(f x_k g) = f y_k g$$라면, 모든 정수 $$q$$와 모든 신호 $$f x_k g$$에 대해 다음이 성립합니다:
$$
T(f x_{k+q} g) = f y_{k+q} g
$$
**설명:**
*   **선형성**: 변환이 신호들의 합을 변환하거나 스칼라를 곱한 신호를 변환할 때, 개별 신호를 변환한 후 합치거나 스칼라를 곱하는 것과 동일한 결과를 냅니다. 이는 벡터 공간에서의 선형 변환 정의와 동일합니다.
*   **시불변성**: 변환의 동작이 시간에 따라 변하지 않는다는 것을 의미합니다. 예를 들어, 오늘 신호에 적용한 변환이 내일 같은 신호에 적용했을 때도 동일한 효과를 내야 합니다. 즉, 신호가 시간상으로 지연되거나 앞당겨져도, 변환 자체는 그 시프트된 신호에 동일하게 작용한다는 뜻입니다.

### 📘 [정리] 정리 16: LTI 변환은 선형 변환이다
이산 시간 신호 공간 $$S$$에서의 선형 시불변 변환은 특별한 종류의 선형 변환입니다.
**의미:** LTI 변환의 첫 두 가지 조건이 선형 변환의 정의와 정확히 일치하기 때문에, 모든 LTI 변환은 선형 변환의 모든 성질을 가집니다.

### 🧠 [예제] Shift 변환 (가장 기본적인 LTI 변환)
신호의 각 요소를 오른쪽으로 한 칸 이동시키는 변환 $$S$$를 생각해 봅시다.
$$S(f x_k g) = f x_{k-1} g$$
즉, 결과 신호의 $$k$$번째 값은 원래 신호의 $$(k-1)$$번째 값입니다.

*   **선형성 확인**:
    *   $$S(f x_k + y_k g) = f (x_{k-1} + y_{k-1}) g = f x_{k-1} g + f y_{k-1} g = S(f x_k g) + S(f y_k g)$$ (덧셈에 대한 분배 만족)
    *   $$S(c f x_k g) = f c x_{k-1} g = c f x_{k-1} g = c S(f x_k g)$$ (스칼라 곱에 대한 분배 만족)
*   **시불변성 확인**:
    *   만약 $$S(f x_k g) = f y_k g = f x_{k-1} g$$ 이면,
    *   $$T(f x_{k+q} g) = f x_{(k+q)-1} g = f x_{(k-1)+q} g = f y_{k+q} g$$ (시불변성 만족)

따라서 Shift 변환 $$S$$는 LTI 변환입니다.

**Inverse Shift 변환**: 왼쪽으로 이동시키는 변환 $$S^{-1}$$은 $$S^{-1}(f x_k g) = f x_{k+1} g$$입니다. $$S^{-1}S(f x_k g) = S^{-1}(f x_{k-1} g) = f x_{(k-1)+1} g = f x_k g$$이므로, $$S^{-1}S = I$$ (항등 변환)입니다.

**Shift 변환 적용 예시:**
아래 표는 델타 신호 $$\delta$$에 $$S$$와 $$S^{-1}$$를 반복적으로 적용했을 때의 결과를 보여줍니다.

| 변환 | 벡터 표현 | 공식 정의 |
|---|---|---|
| $$S^{-2}(\delta)$$ | $$\dots, \underline{1}, 0, 0, 0, 0, \dots$$ | $$w_k = \begin{cases} 1 & \text{if } k=-2 \\ 0 & \text{if } k \neq -2 \end{cases}$$ |
| $$S^{-1}(\delta)$$ | $$\dots, 0, \underline{1}, 0, 0, 0, \dots$$ | $$x_k = \begin{cases} 1 & \text{if } k=-1 \\ 0 & \text{if } k \neq -1 \end{cases}$$ |
| $$\delta$$ | $$\dots, 0, 0, \underline{1}, 0, 0, \dots$$ | $$d_k = \begin{cases} 1 & \text{if } k=0 \\ 0 & \text{if } k \neq 0 \end{cases}$$ |
| $$S^1(\delta)$$ | $$\dots, 0, 0, 0, \underline{1}, 0, \dots$$ | $$y_k = \begin{cases} 1 & \text{if } k=1 \\ 0 & \text{if } k \neq 1 \end{cases}$$ |
| $$S^2(\delta)$$ | $$\dots, 0, 0, 0, 0, \underline{1}, \dots$$ | $$z_k = \begin{cases} 1 & \text{if } k=2 \\ 0 & \text{if } k \neq 2 \end{cases}$$ |

### 🧠 [예제] 이동 평균 (Moving Average) LTI 변환
주어진 신호를 부드럽게 만들거나 필터링하는 데 '이동 평균' LTI 변환이 사용됩니다.
$$m$$을 양의 정수라고 할 때, 시간 주기 $$m$$을 갖는 이동 평균 LTI 변환 $$M_m$$은 다음과 같이 정의됩니다.
$$
M_m(f x_k g) = f y_k g \quad \text{where} \quad y_k = \frac{1}{m} \sum_{j=k-m+1}^{k} x_j
$$
**예제 해설:** 이 변환은 현재 시점 $$k$$를 포함하여 과거 $$m$$개의 신호 값의 평균을 취하여 새로운 신호 값 $$y_k$$를 생성합니다. 예를 들어, $$M_3(f x_k g)$$는 $$y_k = \frac{1}{3}(x_{k-2} + x_{k-1} + x_k)$$가 됩니다. $$m$$ 값이 커질수록 신호는 더 부드러워집니다. 이는 주식 시장의 가격 변동을 완화하여 추세를 파악하는 데 유용하게 사용될 수 있습니다.

## 🟦 Step 3: 신호 부분 공간의 기저 생성

유한한 길이를 가지는 신호들을 다룰 때, 이들을 $$R^{n+1}$$과 같은 익숙한 유한 차원 벡터 공간으로 매핑하여 분석하는 것이 유용합니다.

### 📙 [정의] 길이 $$n$$인 신호들의 집합 ($$S_n$$)
$$S_n$$은 $$k<0$$ 또는 $$k>n$$일 때 $$y_k=0$$인 모든 신호 $$f y_k g$$들의 집합으로 정의됩니다.
**설명:** 이는 특정 시작점(0)부터 특정 끝점($$n$$)까지만 0이 아닌 값을 가질 수 있는 신호들을 의미합니다.

### 📘 [정리] 정리 17: $$S_n$$의 기저
집합 $$S_n$$은 $$S$$의 부분 공간이며 $$R^{n+1}$$과 동형입니다. 그리고 다음 신호들의 집합 $$B_n$$은 $$S_n$$의 기저를 형성합니다.
$$
B_n = \{ \delta, S(\delta), S^2(\delta), \dots, S^n(\delta) \}
$$
**의미:** 이 정리는 길이 $$n$$인 모든 이산 시간 신호가 델타 신호와 이를 반복적으로 시프트시킨 신호들의 선형 결합으로 표현될 수 있음을 의미합니다. 또한 $$S_n$$은 $$n+1$$차원 벡터 공간이므로, $$R^{n+1}$$의 벡터로 표현할 수 있습니다. 이는 우리가 기존에 알고 있던 유한 차원 벡터 공간의 개념을 신호 공간에 적용할 수 있게 해줍니다.

**증명 (간략):**
1.  **부분 공간**: 영 신호가 $$S_n$$에 포함되고, 신호를 더하거나 스칼라 배해도 $$0$$이어야 하는 위치에 $$0$$이 아닌 값을 만들 수 없으므로 $$S_n$$은 $$S$$의 부분 공간입니다.
2.  **생성 집합**: $$S^j(\delta)$$는 $$k=j$$일 때만 $$1$$이고 나머지는 $$0$$인 신호입니다. $$S_n$$의 어떤 신호 $$f y_k g$$도 $$y_0 \delta + y_1 S(\delta) + \dots + y_n S^n(\delta)$$로 쓸 수 있으므로 $$B_n$$은 $$S_n$$을 생성합니다.
3.  **선형 독립**: 만약 $$c_0 \delta + c_1 S(\delta) + \dots + c_n S^n(\delta) = f 0 g$$ (영 신호)라면, 모든 $$k$$ 위치에서 값이 $$0$$이어야 합니다. 이는 $$c_0, c_1, \dots, c_n$$이 모두 $$0$$이어야만 가능하므로, $$B_n$$은 선형 독립입니다.
4.  결론적으로 $$B_n$$은 $$S_n$$의 기저이며, $$n+1$$개의 벡터를 포함하므로 $$n+1$$차원입니다.

### 🧠 [예제] $$S_2$$ 신호를 $$R^3$$ 벡터로 표현하기
$$S_2$$의 기저 $$B_2 = \{ \delta, S(\delta), S^2(\delta) \}$$를 사용하여 다음 신호 $$f y_k g$$를 $$R^3$$의 벡터로 나타내세요.
$$
y_k = \begin{cases} 0 & \text{if } k < 0 \text{ or } k > 2 \\ 2 & \text{if } k = 0 \\ 3 & \text{if } k = 1 \\ -1 & \text{if } k = 2 \end{cases}
$$
**예제 해설:**
먼저 신호 $$f y_k g$$를 기저 벡터들의 선형 결합으로 표현합니다.
$$
f y_k g = 2\delta + 3S(\delta) + (-1)S^2(\delta)
$$
이 선형 결합의 계수들이 바로 좌표 벡터의 성분이 됩니다. 따라서
$$
[f y_k g]_{B_2} = \begin{pmatrix} 2 \\ 3 \\ -1 \end{pmatrix}
$$
이 신호는 $$R^3$$ 공간의 벡터 $$(2, 3, -1)^T$$로 표현될 수 있습니다.

### 📙 [정의] 유한 지지 신호들의 집합 ($$S_f$$)
'유한 지지 신호(finitely supported signal)'는 오직 유한 개의 성분만이 $$0$$이 아닌 신호를 의미합니다. 이러한 신호들의 집합을 $$S_f$$라고 합니다.
**설명:** 주식 일별 가격처럼 매일 길이가 늘어나지만, 특정 시점 이전이나 이후로는 항상 $$0$$인 신호들이 이에 해당합니다. $$S_n$$에 속하는 모든 신호는 유한 지지 신호이지만, 모든 유한 지지 신호가 특정 $$S_n$$에 속하는 것은 아닙니다 (길이가 계속 늘어날 수 있기 때문).

### 📘 [정리] 정리 18: $$S_f$$의 기저
집합 $$B_f = \{ S^j(\delta) \mid j \in \mathbb{Z} \}$$는 무한 차원 벡터 공간 $$S_f$$의 기저입니다.
**의미:** $$S_f$$는 무한히 많은 델타 신호의 시프트 버전으로 생성될 수 있으며, 이러한 신호들은 선형 독립이므로 $$S_f$$는 무한 차원 벡터 공간입니다. 즉, $$S_f$$는 어떤 유한 차원 $$R^n$$과도 동형이 아닙니다.

**증명 (간략):**
1.  **생성 집합**: $$S_f$$의 어떤 신호 $$f y_k g$$도 유한 개의 $$0$$이 아닌 성분만 가지므로, $$y_k \neq 0$$인 범위 $$(p \le k \le q)$$ 내의 $$S^j(\delta)$$들의 선형 결합 $$\sum_{j=p}^{q} y_j S^j(\delta)$$로 표현될 수 있습니다. 따라서 $$B_f$$는 $$S_f$$를 생성합니다.
2.  **선형 독립**: 유한한 수의 $$S^j(\delta)$$들의 선형 결합이 영 신호가 되려면, 모든 계수들이 $$0$$이어야 하므로, $$B_f$$는 선형 독립입니다.
3.  **무한 차원**: $$B_f$$는 무한히 많은 신호들을 포함하므로 $$S_f$$는 무한 차원 벡터 공간입니다.

**주의사항:** 신호 공간 $$S$$ 자체는 $$B_f$$를 기저로 가질 수 없습니다. 기저의 정의에 따라 선형 결합은 항상 '유한한' 수의 벡터와 스칼라만을 사용해야 합니다. 예를 들어, 단위 계단 신호 $$u = \sum_{j=0}^{\infty} S^j(\delta)$$는 무한 합이므로 '선형 결합'으로 간주되지 않습니다. 무한 합은 고차원 수학에서 다루는 주제입니다.

| **길이 $$n$$인 신호들의 집합 ($$S_n$$)** | $$k<0$$ 또는 $$k>n$$일 때 $$y_k=0$$인 신호들의 부분 공간. | $$S_2$$의 신호들은 $$(y_0, y_1, y_2)$$ 형태로 표현 가능 |
| **$$S_n$$의 기저 ($$B_n$$)** | $$B_n = \{ \delta, S(\delta), \dots, S^n(\delta) \}$$. $$S_n$$은 $$R^{n+1}$$과 동형인 $$n+1$$차원 공간. | $$B_2 = \{ \delta, S(\delta), S^2(\delta) \}$$ |
| **유한 지지 신호들의 집합 ($$S_f$$)** | 오직 유한 개의 성분만이 $$0$$이 아닌 신호들의 부분 공간. | 모든 $$S_n$$ 신호, 그리고 무한히 길어질 수 있는 일부 신호 |
| **$$S_f$$의 기저 ($$B_f$$)** | $$B_f = \{ S^j(\delta) \mid j \in \mathbb{Z} \}$$. $$S_f$$는 무한 차원 벡터 공간. | $$S_f$$는 $$R^n$$과 동형이 아님 |

### 🔸 연습문제3
변환 `T(fxkg) = (I - S^2)(fxkg)`의 핵(kernel)에 속하는 0이 아닌 신호를 Table 1에서 찾으세요. 여기서 `I`는 항등 변환(identity transformation)이고 `S`는 시프트 변환입니다.

{: .answer-title }
> 정답 보기
>
> 정답: 교대 신호(alternating signal) `α` (`fakg, where ak = (-1)^k`)
>
> 해설:
> 변환 `T(fxkg) = (I - S^2)(fxkg)`를 풀어쓰면 `T(fxkg) = fxkg - S^2(fxkg)`가 됩니다.
> `S^2(fxkg)`는 `fxk-2g`와 같습니다.
> 따라서 `T(fxkg) = fxk - xk-2g`입니다.
> 핵에 속하는 신호 `fxkg`는 `T(fxkg) = f0g`를 만족해야 합니다. 즉, `xk - xk-2 = 0`이므로, 모든 정수 `k`에 대해 `xk = xk-2`여야 합니다. 이 조건은 신호의 값이 두 간격마다 반복된다는 것을 의미합니다.
> Table 1에서 교대 신호 `α`는 `ak = (-1)^k`로 정의됩니다.
> 이 신호에 대해 `ak = (-1)^k`이고, `ak-2 = (-1)^(k-2) = (-1)^k * (-1)^-2 = (-1)^k * (1/((-1)^2)) = (-1)^k` 입니다.
> 따라서 `ak - ak-2 = (-1)^k - (-1)^k = 0`이 됩니다.
> 이는 교대 신호 `α`가 `I - S^2` 변환의 핵에 속하는 0이 아닌 신호임을 보여줍니다.
